# Reference Tabs

Open semantic references in a VS Code editor tab. Results are grouped by file and show the matching source line. Click a result to jump to it.

Put the cursor on a symbol, then run **Find All References in Tab** from the Command Palette or editor context menu. The active language extension supplies the references; this is not a text search. For Go and C#, install their respective language extensions and open the relevant workspace.

To try the extension from a local checkout, open the folder with `code --extensionDevelopmentPath="$(pwd)"` and then open a workspace in the development window.
